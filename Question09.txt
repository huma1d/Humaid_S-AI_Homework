7)After creating these directories,I used `cd ..` to return to the `pipeline` directory and created another directory named `artifacts` using `mkdir artifacts`.I then entered it and created a subdirectory named `old` to store older project artifacts.

9)Then I used `chmod 770 artifacts` to give the owner and group read,write and execute permissions on the `artifacts` directory,while denying all permissions to other users.

11)Then I entered the `stages` directory using `cd stages` and moved into the `build` directory using `cd build`.

15)After that,I used `cd ..` twice to move back from the `build` directory to the main `pipeline` directory,passing through the `stages` directory.
16)Then I entered the `artifacts` directory using `cd artifacts` and moved into its `old` subdirectory using `cd old`.
17)Inside the `old` directory,I used the `touch` command to create three files named `build.log`,`test.log` and `deploy.log`.These files can be used to store logs related to the build,testing and deployment processes.
