  Approach:
1)First we navigated into the api-service folder
2)We initialized the api-service folder using git init
3)We staged the README.md file
4)Then we commited with the message "Add documentation"
5)Then we staged three files simultaneously server.js routes.js & package.json
6)Then we commited all the staged files under a single message "Add Server Files"
7)Finally we checked the status of the git and then checked the commit history using git log

  Result:
The `api-service` directory has been initialized as a Git repository. The `README.md` file was staged and committed with the message "Add documentation". Then, the files `server.js`, `routes.js`, and `package.json` were staged and committed together with the message "Add Server Files". Finally, the repository status was checked using `git status`, and the commit history was displayed using `git log`.
