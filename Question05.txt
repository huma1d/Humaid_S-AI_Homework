  Question Title
Execute a python script directly
  Question Link:
https://my.newtonschool.co/playground/code/ufddfctmocny
  Solution:
echo '#!/usr/bin/env python3' > hello.py
echo 'print("Hello from Python")' >> hello.py
chmod 777 hello.py
./hello.py

  Approach:
1)Firstly,using the echo command i created and as well as wrote a line in a file,the line consisted of shebang(#!)followed by /usr/bin/env python3 so that the OS can know that this file needs to be executed using the python3 language,which is stored somewhere inside the directory we gave it
2)Then we gave the syntax of the print command,and inside it we wrote "Hello From Python" so that as soon as the file is executed this line would get printed
3)We gave the executable permission to hello.py
4)We execute the file for the expected outcome

  Results:
The `hello.py` file has been created with a shebang that specifies Python 3 as the interpreter, followed by a print statement that displays `Hello From Python`. The file was given executable permission and then executed successfully, displaying the expected output.
