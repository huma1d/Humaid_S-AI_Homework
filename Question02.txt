  Question Title:
Create a project folder structure
  Question Link:
https://my.newtonschool.co/playground/code/ew62ozjyub63

   Solution:
cat > /box/create-service << EOF
mkdir  service
cd service
mkdir  controllers
mkdir  models
mkdir  routes
mkdir  middleware
echo 'console.log("Server started");' > server.js
echo "API Service" > README.md
EOF
chmod +x /box/create-service
/box/create-service
cat service/server.js
cat service/README.md
ls -R service
