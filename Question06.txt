  Question Title:
Simplyfing the compilation process
  Question Link:
https://my.newtonschool.co/playground/code/r1h3wy35c8h0
  Solution:
echo 'gcc hello.c -o hello' > build.sh
chmod 777 build.sh
./build.sh
./hello
  
  Approach:
1) Firstly, using the `echo` command, I created a file named `build.sh` and wrote the line `gcc hello.c -o hello` inside it. This line contains the command to compile the C program named `hello.c` using the GCC compiler and generate an executable file named `hello`.
2) Then, using the `chmod 777 build.sh` command, I gave the file `build.sh` read, write, and execute permissions to the owner, group, and other users, allowing the script to be executed.
3) After that, using `./build.sh`, I executed the script. The `./` specifies that the file is located in the current directory. When executed, the script runs the command written inside it, which compiles `hello.c` using GCC and generates an executable file named `hello`, provided the compilation is successful.
4) Finally, using `./hello`, I executed the compiled program from the current directory. This runs the machine code generated by the compiler and produces the expected output of the C program.

  Results:
The `build.sh` script has been created with the command to compile `hello.c` using GCC. The script was given executable permissions and executed successfully, generating an executable file named `hello`. Finally, the compiled program was executed using `./hello`, producing the expected output of the C program.
